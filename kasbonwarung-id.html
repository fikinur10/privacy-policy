Kebijakan Privasi — BukuKasbon

Tanggal berlaku: 1 November 2026 · Kontak: fiknur@ciplux.com

BukuKasbon adalah aplikasi buku kasbon warung yang dikembangkan oleh PT CIPLUX MAHDANI SOLUTION. Anda mencatat pelanggan, utang (kasbon), dan pembayaran, dan aplikasi menghitung sisa tagihan tiap pelanggan. Aplikasi dapat digunakan tanpa membuat akun dan berfungsi sepenuhnya secara offline.

1. Data yang Kami Kumpulkan

Kami tidak meminta Anda membuat akun. Kami tidak mengumpulkan nama, alamat email, nomor telepon, lokasi, kontak, atau informasi pribadi lainnya ke server kami — aplikasi ini tidak memiliki server dan tidak memiliki izin internet, sehingga tidak ada data yang dapat dikirim keluar dari perangkat Anda. Aplikasi ini juga tidak memuat SDK analitik atau SDK iklan pada versi saat ini.

2. Data yang Tersimpan di Perangkat Anda

Data berikut dibuat dan disimpan hanya di perangkat Anda (basis data dan penyimpanan lokal aplikasi):

  • Pelanggan yang Anda catat: nama, nomor telepon (opsional, untuk pengingat via WhatsApp), dan catatan.
  • Entri kasbon: nominal, catatan, dan tanggal jatuh tempo bila ada.
  • Entri pembayaran: nominal, catatan, dan tanggal bayar.
  • Label, status arsip, dan pengaturan aplikasi.

Data tersebut tidak pernah meninggalkan perangkat Anda kecuali melalui tindakan berbagi atau ekspor yang Anda lakukan sendiri sebagaimana dijelaskan pada bagian 4.

3. Izin yang Digunakan

Aplikasi ini tidak meminta izin Android apa pun pada versi saat ini. Pengingat dan notifikasi tidak dipakai; pengingat kepada pelanggan dilakukan lewat WhatsApp hanya bila Anda mengetuknya sendiri (lihat bagian 4).

4. Berbagi Data dan Layanan Pihak Ketiga

Kami tidak membagikan data Anda kepada pihak ketiga mana pun dan tidak menjual data pengguna. Aplikasi ini tidak terhubung ke layanan pihak ketiga mana pun, kecuali tindakan yang Anda mulai sendiri berikut ini:

Anda dapat mengekspor cadangan data dalam format JSON melalui Pengaturan. Berkas cadangan itu tersimpan di folder aplikasi di perangkat Anda dan sepenuhnya berada dalam kendali Anda; aplikasi tidak mengunggahnya ke mana pun. Pemulihan cadangan bersifat menggabung — data lama tidak ditimpa.

Jika Anda mengetuk pengingat atau bagikan via WhatsApp, aplikasi membuka tautan WhatsApp (wa.me) dengan nomor dan pesan yang Anda lihat; sejak titik itu, data tersebut tunduk pada kebijakan privasi WhatsApp. Aplikasi tidak mengirim pesan sendiri tanpa ketukan Anda.

Pembelian Pro sekali bayar, bila tersedia, diproses oleh Google Play; kami tidak menerima atau menyimpan detail kartu Anda. Status Pro dicatat secara lokal di perangkat Anda.

Jika di masa mendatang kami menambahkan layanan pihak ketiga, kami akan memperbarui kebijakan privasi ini dan disclosure Data Safety di Google Play sebelum merilis pembaruan tersebut.

5. Anak-Anak

Aplikasi ini adalah aplikasi utilitas untuk pengguna umum dan tidak ditujukan untuk mengumpulkan data anak-anak. Kami tidak secara sengaja mengumpulkan informasi pribadi dari anak-anak.

6. Penyimpanan dan Penghapusan Data

Karena kami tidak menyimpan data pribadi di server, tidak ada data pribadi Anda yang perlu dihapus dari server kami. Data yang tersimpan di perangkat Anda dapat dihapus dengan menghapus data aplikasi melalui pengaturan perangkat atau dengan menghapus (uninstall) aplikasi. Menghapus pelanggan dari aplikasi bersifat arsip, bukan hapus permanen dari basis data, kecuali Anda menghapus data aplikasi atau aplikasinya.

7. Perubahan Kebijakan Ini

Jika kami mengubah kebijakan privasi ini, kami akan memposting versi terbaru di halaman ini dan memperbarui tanggal berlaku di atas.
